# 로드맵

| 단계 | 내용 | 완료 조건 | 상태 |
|---|---|---|---|
| M0 기반 | 저장소, 프로토콜 v1, Swift·Kotlin 코덱, CI, 전송·페어링, 앱 셸 | 두 앱이 실제 기기에서 페어링되고 연결이 유지된다 | 진행 중 |
