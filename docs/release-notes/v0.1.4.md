# Graft v0.1.4

Fixes the pairing and transfer defects that could leave the app looking connected while doing
nothing, plus the ones that killed a link or a file in the middle.

## Fixes since v0.1.3

- **QR pairing works.** A scan saved the Mac's fingerprint as "already paired", so the phone sent
  `hello` and the Mac refused it. The phone now asks to pair and treats the link as complete only
  after the Mac accepts.
- **Pairing is a boundary.** Any device can complete TLS while a pairing window is open; clipboard
  writes, notification banners, and transfers now run only for a peer the Mac actually paired.
- **The link stays up.** The phone answers the Mac's heartbeat and file data counts as activity, so
  an idle connection or a long transfer no longer reconnects every 60 seconds.
- **Sent files are recorded.** A completed send used to sit at "In progress · 100%" forever.
- **Large files are streamed.** The Mac sends one 64 KiB chunk at a time with a 1 MiB window instead
  of loading the whole file into memory, and Android waits when the socket queue fills instead of
  overrunning it.
- **Failures are visible.** A full disk, a revoked storage permission, or a refused frame becomes a
  failed row instead of killing the connection or freezing the progress bar.
- **History is reliable.** Rows survive a restart, disconnecting no longer empties the Files tab, a
  reused transfer id no longer overwrites an older row, and interrupted receives resume.
- **Settings stick.** macOS clipboard and notification-preview choices persist, previews start off,
  and Android asks for notification permission so the background notice is visible.
- **Disconnects are immediate.** The Mac drops the session when the socket closes, received files
  carry the quarantine flag, and a failed Bonjour registration is reported instead of hiding the
  Mac from discovery.
- **Privacy policy updated.** Transfer history is described as stored on the device, and macOS has
  its own removal steps.

## Install

- Android: `Graft-0.1.4.apk`, or the Play testing track (versionCode 5).
- macOS: `Graft-0.1.4.dmg`; ad-hoc signed and not notarized, so the first launch needs approval
  (System Settings → Privacy & Security → Open Anyway on macOS 15+).

## Verification

Protocol fixtures, Android core 154 / app 172, Swift package 117, macOS app 57 plus the UI test, and
both E2E scripts (pairing, 5 MiB transfer) pass.
