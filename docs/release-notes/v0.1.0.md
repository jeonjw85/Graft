# Graft v0.1.0

First release of Graft: a LAN-only bridge between a Mac and an Android phone.

## What works

- **Pairing** by QR code, or by a six-digit code with the Mac's fingerprint prefix and address.
  The phone pins the Mac's SPKI fingerprint; a manual pairing ends with the same pin as a scan.
- **File transfer both ways** with resume, SHA-256 verification, and received files written to
  `Download/Graft` on Android and to the Mac's chosen folder.
- **Clipboard text both ways**: Mac to Android automatically while the app is open, Android to Mac
  with a button. Text only, 256 KiB limit.
- **Android to Mac notifications** for the apps you allow; the filter runs on the phone.
- **Reliable reconnect**: heartbeat, immediate retry when the network returns, address rediscovery
  by Bonjour fingerprint, and pairing that survives app restarts.

## Install

See [install.md](../install.md). The macOS build is **unsigned and not notarized**; the first launch
needs the right-click Open step.

## Known limitations

- macOS builds are not notarized (no Developer ID).
- Pairing is one-to-one.
- Clipboard supports text only; images are planned for a later release.
- Notifications travel Android to Mac only; macOS has no public API for reading other apps'
  notifications.
- The Android app is not on Google Play yet; the APK is signed with the release key so updates keep
  working.

## Verification

- Protocol fixtures, Swift and Kotlin unit tests, a macOS UI test that drives the real popover,
  and two end-to-end scripts (pairing and a 5 MiB transfer).
- Device checks: real Android app paired with the real Mac app, files received into MediaStore,
  clipboard round trip, notification forwarding.
