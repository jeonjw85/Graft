# Graft v0.1.2

Adds the missing app icons. v0.1.1 builds carried the platform's placeholder icon, and Google Play
rejects a bundle without one.

## Changes since v0.1.1

- Android launcher icon: adaptive icon (dark background, blue chain link) for API 26+, with legacy
  PNGs for older densities and a round variant.
- macOS app icon (`.icns`), shown in Finder and the DMG.
- No behavioural changes.

## Install

- Android: `Graft-0.1.2.apk`, or the Play testing track (versionCode 3).
- macOS: `Graft-0.1.2.dmg`; the build is unsigned, so the first launch needs the right-click Open
  step described in `docs/install.md`.

## Verification

Protocol fixtures, Swift 114, Kotlin core 153 / app 139, macOS 55, the macOS UI test, and both E2E
scripts pass. The packaged APK reports its own icon for every density, and the DMG's bundle reports
version 0.1.2 with `AppIcon.icns` present.
