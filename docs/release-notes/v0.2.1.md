# Graft v0.2.1

A focused UI/UX polish release across both Android and macOS while keeping Graft's shared dark palette intact.

## Highlights

### Android UI polish
- Added a 3-tier dark surface hierarchy (`#0E1116` background, `#151A21` cards with subtle `1dp` `#2A3240` borders, `#1C232C` icon containers) and refined typography weights.
- Replaced the Settings screen text `< Back` link with a proper Material 3 `TopAppBar` and back icon button.
- Upgraded the Connection screen with 2-column quick action tiles (`Send file to Mac` / `Send clipboard`) when connected, a top-right Settings shortcut, status-tinted hero borders, and leading icon badges across all rows.
- Polished Files & Alerts screens with centered icon empty-state cards, rounded-cap transfer progress bars, compact cancel icon buttons, bordered extension tiles, and a bordered dark bottom navigation bar.

### macOS UI polish
- Redesigned the menu bar popover with a status-tinted hero card, capsule phone battery badge, 3-column hoverable quick-action icon tiles (`Send files…` / `Send clipboard` / `Ring phone`), dashed drag-and-drop tip banner, custom capsule progress cards, and a clean icon footer bar.
- Framed the pairing window's QR code and manual-entry details inside bordered cards with an accented Copy Details action.

## Install

- Android: `Graft-0.2.1.apk` (versionCode 8).
- macOS: `Graft-0.2.1.dmg`; ad-hoc signed and not notarized, so the first launch needs approval
  (System Settings → Privacy & Security → Open Anyway on macOS 15+).

## Verification

Android `:app:testDebugUnitTest` (including `GraftPaletteTest` and `LocalizationParityTest`) and macOS `GraftAppTests` (69 tests including `PaletteTests` and `SettingsTextTests`) all pass.
