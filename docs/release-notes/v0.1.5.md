# Graft v0.1.5

One change: Play no longer hides Graft from devices without a Wi-Fi radio.

## Fixes since v0.1.4

- Removed the unused `CHANGE_WIFI_MULTICAST_STATE` permission, which made Android declare
  `android.hardware.wifi` as required. The manifest now states explicitly that Wi-Fi is optional, so
  phones, tablets, desktop, and XR devices on Ethernet or a USB adapter can install the app.
- Nothing else changed; the pairing, heartbeat, and transfer fixes from v0.1.4 are included.

## Install

- Android: `Graft-0.1.5.apk`, or the Play testing track (versionCode 6).
- macOS: `Graft-0.1.5.dmg`; ad-hoc signed and not notarized, so the first launch needs approval
  (System Settings → Privacy & Security → Open Anyway on macOS 15+).

## Verification

Protocol fixtures, Android core 154 / app 172, Swift package 117, macOS app 57 plus the UI test, and
both E2E scripts pass.
