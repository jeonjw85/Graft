# Graft v0.1.1

The first build uploaded to Google Play (internal and closed testing).

## Changes since v0.1.0

- The connection screen leads with the link state; pairing another phone is a secondary action, and
  Reconnect only appears while the link is down.
- A dropped connection now retries immediately instead of stalling the reconnect loop.
- Permission prompts name what is missing and open the relevant system settings.
- Store assets: icon, feature graphic, and real screenshots.

## Install

- Android: from the Play testing track (opt-in link), or `Graft-0.1.1.apk`.
- macOS: `Graft-0.1.1.dmg` (same app as v0.1.0; the version is bumped so both platforms share one
  release). See `docs/install.md`.
