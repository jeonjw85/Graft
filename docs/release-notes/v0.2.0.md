# Graft v0.2.0

A major beta upgrade covering transfer performance & stability, OS-native sharing, continuity features, and full English/Korean localization.

## Highlights

### Performance, stability & protocol compliance
- Throttled resume checkpoint writes to 1 MiB intervals (plus first chunk and disconnect/cancel flush) on both platforms, eliminating per-chunk disk writes during large transfers.
- Moved Android outgoing file streaming off the WebSocket receive loop with OkHttp queue backpressure (`pendingBytes()`) and blocking inbound binary delivery (`trySendBlocking`), plus automatic cleanup of `cacheDir/outgoing/` temp files.
- Enforced 30-second transfer stall timeouts (discarding partial files per protocol §3.1) and strict control/binary frame decode error replies (`bad_payload`, `proto_unsupported`, oversized close).
- Improved macOS LAN IP detection to prefer physical interfaces (`en0`, `en*`) over VPN/Docker virtual adapters (`utun*`, `bridge*`), and propagated real MIME types for opening received files.

### Transfer & macOS polish
- Added per-transfer cancel buttons, live transfer speed (KiB/s, MiB/s) and ETA, and multi-file selection on both platforms.
- Added macOS popover drag-and-drop, automatic folder zipping on send, custom receive directory selection, persistent macOS transfer history with per-file Reveal in Finder, and Launch at Login (`SMAppService`).
- Added opt-in automatic Mac screenshot forwarding (disabled by default to avoid unsolicited Desktop permissions).

### Clipboard, OS integration & continuity
- Implemented automatic Mac -> Android clipboard polling (skipping concealed/transient password-manager entries and echo loops) plus clipboard image sending as chunked PNG transfers.
- Fixed Android foreground clipboard auto-copy to work across all tabs, added a Send Clipboard button to the Connection tab, and added an Android Quick Settings tile & persistent notification action for one-tap clipboard sharing.
- Added Android Share Sheet support (`ACTION_SEND` and `ACTION_SEND_MULTIPLE`) with cold-start queuing for files and text.
- Added phone battery status indicator and Ring My Phone (alarm-volume ring + vibration with notification stop action and 20s timeout).
- Added macOS notification banner subtitles (`title`) and Android `EXTRA_BIG_TEXT` support, inline notification replies (`RemoteInput`), and two-way notification dismiss synchronization.

### Localization
- Added full English and Korean (`en` / `ko`) localization across both macOS (`Localizable.strings`) and Android (`strings.xml`), following the system language automatically.

## Install

- Android: `Graft-0.2.0.apk`, or the Play testing track (versionCode 7).
- macOS: `Graft-0.2.0.dmg`; ad-hoc signed and not notarized, so the first launch needs approval
  (System Settings → Privacy & Security → Open Anyway on macOS 15+).
