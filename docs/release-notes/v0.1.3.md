# Graft v0.1.3

Fixes the two things testers found most annoying: Disconnect did not stick, and the connection
notification was in the way. Adds a Settings screen and keeps the transfer list across restarts.

## Changes since v0.1.2

- **Disconnect is remembered.** Reopening the app no longer reconnects behind your back; press
  Reconnect to start again.
- **The connection notification is quiet.** Minimum importance, no sound, no vibration, no re-alert,
  and it disappears when you disconnect.
- **Settings screen.** Background (battery), Clipboard, Notifications, and About moved off the
  Connection tab, which now shows only the link and its actions.
- **Recent transfers survive a restart** (last 20, with destination and failure reason). Forget this
  Mac clears them.

## Install

- Android: `Graft-0.1.3.apk`, or the Play testing track (versionCode 4).
- macOS: `Graft-0.1.3.dmg`; unsigned, so first launch needs right-click > Open.

## Verification

Protocol fixtures, Swift 114, Kotlin core 153 / app 154, macOS 55, the macOS UI test, and both E2E
scripts pass. On a device: notification appears silently in the Silent section, Disconnect stops the
service and survives an app restart, Reconnect clears the stopped state.
